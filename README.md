# Lab11
In this lab, I learned how to use arrays and loops to control four LEDs with just a few lines of code. I also learned how JSON lets the ESP32 send its results as one clean message and take commands from the Serial Monitor. At the end, I had a small sensor reporter with an LED bar graph, and it felt cool to see my code control real lights.
# Required Equipment 
-	ESP32 Development Board (Espressif ESP32-DevKitC)
-	4 × LEDs (any colours)
-	4 × 220 Ω resistors
-	1 × push button
-	1 × 10 kΩ potentiometer
-	Breadboard
-	Jumper Wires
-	USB Cable
# Software
-	Visual Studio Code
-	PlatformIO
-	Serial Monitor
-	ArduinoJson library, version 7 (added in platformio.ini)
-	lab11_starter_main.cpp file (provided by my instructor)
